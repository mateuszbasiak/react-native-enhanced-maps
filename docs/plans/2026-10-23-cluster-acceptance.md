# Component clustering acceptance plan

Exercise the current Marker.cluster contract through the existing Debug fixture,
without restoring retired source-query APIs. Extend Debug-only collection with
mounted custom-cluster handles, camera evidence and explicit fixture controls.
Audit lazy IDs/metadata, count and expansion, default rendering, opt-out markers,
coordinate/count changes, style reload/remount and stale handles on both simulators.
Keep deterministic 1k/10k coincident membership separate from physical-device
performance and spatial parity. Record bounded results and remaining gaps; fix
observed implementation issues with regression coverage before publishing an
independent PR against main.
