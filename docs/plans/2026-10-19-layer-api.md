# Source and layer API implementation plan

**Goal:** Implement the agreed Mapbox-like separation between geographic sources and rendering layers, starting with native GeoJSON line/fill rendering.

**Architecture:** MapView consumes declarative GeoJSONSource/LineLayer/FillLayer children into a validated source/layer graph. Stable IDs identify resources; revisions identify data replacements. Sources and layer definitions cross Fabric as separate props, so style changes do not resend source data. Native adapters own projection and rendering; unsupported types fail explicitly. Future wind sources and particle layers extend the graph rather than a separate screen canvas API.

**Tech stack:** React 19, Fabric Codegen, MapKit overlays, Google Maps polygons/polylines.

1. Test graph compilation: shared sources, stable layer order, fragments, invalid IDs/references/geometry/styles, and bounded data.
2. Implement typed source/layer descriptors and declarative React components. Enforce explicit revisions and finite GeoJSON [longitude, latitude] positions. Empty scenes remove content.
3. Add independent native source/layer props and map-scoped lifetime. Validate native payloads and reject stale source replacements. Reconcile styles without recreating geometry and remove dependent layers before releasing source state.
4. Render line/polygon geometry with each SDK, including multilines, multipolygons and polygon holes. Ordering applies within the native shape-overlay group; basemap labels, annotations and arbitrary custom GPU composition are not portable promises.
5. Add a route and area example plus source/style/visibility/removal scenarios. Run contracts, declarations, Codegen, packages, production bundles and native builds; report runtime evidence separately.

Public authoring:

```tsx
<MapView>
  <GeoJSONSource id="routes" data={routes} revision={1}>
    <LineLayer id="outline" style={{ lineColor: '#123456', lineWidth: 8 }} />
    <LineLayer id="route" style={{ lineColor: '#0088ff', lineWidth: 4 }} />
  </GeoJSONSource>
</MapView>
```

GeoJSON sources may be shared through explicit source IDs. Layer order is declaration order within the shape group. Geometry support is Point/MultiPoint/LineString/MultiLineString/Polygon/MultiPolygon; point sources are accepted for future layer kinds but these initial line/fill layers ignore incompatible features. No expression, clustering or GPU support is implied by this first slice.
