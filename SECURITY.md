# Security policy

This repository is experimental and has no supported production release. Security
fixes target the current development branch; historical experiments and unpublished
snapshots do not have separate maintenance branches or a response-time guarantee.

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/mateuszbasiak/react-native-enhanced-maps/security/advisories/new).
Private reporting was enabled and verified on 2026-10-23. Do not put exploit details,
tokens, signing material, private coordinates or application metadata in public
issues, pull requests or screenshots.

Include the affected commit/package version, RN/MapLibre/WebGPU versions, platform,
OS/device, build mode, impact, reproduction and any sanitized proof of concept.
Share the minimum data needed to reproduce. If a credential was exposed, revoke it
through its owner rather than posting the replacement in the report.

Maintainers should reproduce privately, assess affected versions, coordinate a fix
and regression coverage, and agree on disclosure timing with the reporter. Publish
an advisory with affected/fixed versions when appropriate. Do not promise a fix or
resolution date before assessing the report. Public release credential/identity
ownership remains an open release gate.
